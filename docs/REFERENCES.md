# References: every code, text, image, font, data set and tool we used (task N4)

For the Project page field **"Space Agency Partner Data and Other References"**. The NASA Space Apps guide asks us to list everything we used, even
if it is open source or freely available, and to confirm we used no copyrighted material without permission. Each licence below was checked
against the files in this repository (fonts and Chart.js carry their licence in the repository; the rest are standard, well-known licences).
We used **no data from the 2026 Space Agency Partners**.

## Paste-ready block

**NASA data and resources.** NASA Life Sciences Data Archive, WinSCAT test battery (Flight Analog), UTMB bed-rest Campaign 3, DOI
10.83263/sbne-th55 (analysis results only; the raw files are not redistributed). NASA photograph "Man and Machine" (Image Credit: NASA),
used for the spacesuit glove on the landing page. Background reading only: NASA Reaction Self Test record (NTRS 20090029851) and the Human
Research Program Behavioral Health evidence report (NTRS 20250001454). Details: `docs/NASA_DATA.md`.

**Code and libraries.** Python, Flask (BSD-3-Clause), NumPy (BSD-3-Clause), SQLite through Python's standard library (public domain),
Chart.js 4.4.1 (MIT, vendored in `app/static/vendor/`), and our own code in this repository (MIT, `LICENSE`).

**Fonts.** Instrument Sans, Instrument Serif and JetBrains Mono (SIL Open Font License 1.1, self-hosted in `app/static/fonts/` with the licence texts).

**Images and art.** Michelangelo, *The Creation of Adam* (public domain; Wikimedia Commons reproduction), the human hand on the landing page;
the NASA photograph above; our own mark (drawn in code). Sources, checksums and processing: `docs/ASSETS.md`. The stacked-sessions chart
form is inspired by Harold D. Craft Jr.'s 1970 pulsar plot (idea only; no artwork or code used).

**Development tools (not part of the running product).** pytest (MIT), Playwright (Apache-2.0) for browser checks and screenshots, axe-core
(MPL-2.0) for the accessibility audit, and, for preparing the landing images only, Pillow (HPND), NumPy and OpenCV (Apache-2.0).

**AI assistance.** AI coding assistants (Claude, by Anthropic) wrote much of the code, tests and documentation under the team's direction.
No AI-generated image, audio or video is used. Full account: `docs/AI_USE.md`.

**Our own data.** A two-person volunteer pilot (aggregate timing numbers only, pseudonyms, `docs/pilot/`) and simulated crews generated by our
own code (`ml/synth.py`).
